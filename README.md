# esaKITs — Japanese Flashcards

**Japanese Flashcards v1.19 Beta**

日本語の動詞活用練習を中心に、授業での提示と学習者の個人練習の両方に使えるブラウザ版フラッシュカードです。

## 使う

GitHub Pages 公開版：

```text
https://esakits.github.io/japanese-flashcards/
```

ブラウザで開くだけで利用できます。インストールは不要です。

## 主な機能

- Teacher Mode / Learner Mode
- 内蔵プリセット 62項目
- ます形・て形・辞書形・ない形・た形・意向形・可能形・受け身形・条件形
- かな／漢字／ルビ表示
- 問題側・答え側を別々に設定
- フォント、文字サイズ、太さ、文字色、背景色の調整
- PC内フォントの読み込み
- Light / Regular / Medium / Bold など、実在するフォントウェイトの判定
- UD Digi 系フォントを一覧上部にまとめて表示
- 自動改行
- 任意改行
- 改行せず、必要な場合だけ自動縮小
- プレビュー上半分／下半分をクリックして対応する設定へ移動
- 全画面表示
- JSONによるデータセット保存・読み込み
- CSV / TSV / TXT の読み込み、CSV保存
- `dir="auto"` による右から左へ書く言語の自動判定

## 基本的な使い方

1. 出題する活用形と、答えとして表示する活用形を選びます。
2. 必要に応じて、かな／漢字／ルビ、フォント、文字サイズなどを調整します。
3. Teacher Mode では授業提示用、Learner Mode では個人練習用として使えます。
4. 独自データを使う場合は、CSV / TSV / TXT またはデータセットJSONを読み込みます。

## PC内フォントについて

「PCのフォントを読み込む」は、対応ブラウザの Local Font Access 機能を利用します。

利用時に、ブラウザからPC内フォントへのアクセス許可を求められる場合があります。  
この機能に対応していない環境でも、基本的なフラッシュカード機能は利用できます。
